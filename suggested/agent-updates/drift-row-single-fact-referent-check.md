# Convention: a drift row binds one fact — confirm both quotes share the referent, and record plausible partial reconciliations in the row

**Rule.** Before registering a drift, check that the competing quotes actually assert values for the **same fact**. If one quote's referent is ambiguous — it could plausibly be read as describing a different fact, in which case there is no conflict — the drift is still registered (the conflict reading is live and the fact still needs freezing), but the row records the candidate partial reconciliation explicitly as one of the possible canonical outcomes. The ambiguity is resolved by the adjudication's ground-truth step, never by the registrant picking the charitable reading and declining to register.

**Grounding.**
- `suggested/workflows/reconcile-grok-model-pick-persistence-drift.md`: "The values may also be partially reconcilable — Value A's sentence ('Choice is persisted in `~/.agent-tui/runtime.toml`') could have meant the *runtime* choice, not the model choice — which is exactly why the fact needs adjudication rather than a guess: a doc's rationalization of an inconsistency is not evidence."
- The same workflow's step 1 states the disputed fact precisely ("where the Grok model selection persists") and enumerates the outcome space (a runtime.toml key / sampler-side state / not persisted) — the ambiguous reading appears as an outcome, not as a reason to skip registration.
- The analogous rule exists for lifecycle maps — "confirm a dual-owner collision is genuine before resolving — adjacent stages lumped by map wording are re-lettered, not merged" — but no listed convention applies the genuineness check to drift registration.

**Why:** the two failure modes sit on either side of the check. Registering without it produces rows that fight over nothing — two sentences about different facts frozen as a conflict, blocking edits to both until someone notices. Resolving the ambiguity informally at registration is worse: the charitable reading ("they probably meant the runtime choice") is precisely the kind of rationalization the evidence rules exclude, and if it is wrong, the drift goes unregistered and both values stay live. Putting the ambiguity in the row keeps the fact frozen while ensuring the adjudicator tests the partial-reconciliation reading against ground truth like any other candidate value.

**How to apply:** when registering, write the disputed fact as a single precise question and check each quote answers *that* question. If a quote admits a reading under which it answers a different question, add the reading to the row's outcome enumeration with a note on what evidence would confirm it (e.g. which runtime.toml key actually changes on the wire). At adjudication, the ground-truth probe must discriminate between the conflict reading and the partial-reconciliation reading — a probe that only tests one is incomplete.
