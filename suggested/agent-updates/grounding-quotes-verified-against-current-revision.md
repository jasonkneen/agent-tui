# Convention: a grounding quote is verified against the current revision of its source — an earlier-revision quote is a phantom-grounding signal

**Rule.** A quote cited as grounding (in a convention doc, a drift-ledger value, or an adjudication) carries full evidentiary weight only if the current revision of the quoted source still contains it. Before weighing any quoted value, re-open the source and confirm the sentence is still there. A quote that survives only in an earlier revision — the source has since been edited and no longer says it — is a **phantom-grounding signal**: the value is not disqualified, but it is downgraded below any value grounded in the source's current text, and the mismatch is recorded in the ledger row.

**Grounding.**
- `suggested/workflows/reconcile-model-scope-drift.md`: if shipped behavior matches Value B, "note that Value A's own grounding quote ('`/model` only switches **Grok** models') was lifted from an *earlier revision* of `docs/LOCAL_CLI_AUTH.md` — the convention doc is phantom-grounded."
- `suggested/workflows/reconcile-grok-model-pick-persistence-drift.md`, step 1: "Value A's quote is lifted from an earlier revision of a doc whose current text no longer contains it (a phantom-grounding signal)."
- The workspace already has a repair skill for the downstream state (repair a phantom-grounded convention doc: re-quote, re-ground, or retire) — this convention names the *detection* step that both reconciliations performed independently at adjudication time.

**Why:** the extraction law says a rule with no quotable source is speculation — but a quote checked once at authoring time can silently rot when its source is revised. Both registered instances of this failure involved the same doc (`docs/LOCAL_CLI_AUTH.md`) being edited after a convention doc quoted it, leaving the convention doc asserting a dead rule with apparently solid grounding. Without a revision-currency check, a phantom quote reads exactly like a live one, and an adjudicator who trusts it will pick the superseded value.

**How to apply:** when registering a drift or adjudicating one, re-read each competing value's source at its cited path and confirm the verbatim quote is present in the current text; note "current" or "earlier revision only" next to each value in the ledger row. When a phantom quote is found, weigh it below current-revision and "(shipped)"-marked claims, and route the doc that carries it to the phantom-grounding repair skill after the row closes. When authoring new grounding, quote the source's current revision and record the source's modification date alongside the quote.
