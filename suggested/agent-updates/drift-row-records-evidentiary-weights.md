# Convention: a drift-ledger row records each competing value's evidentiary-weight signals at registration

**Rule.** When a drift is registered, the row records — alongside each value's verbatim quote, source path, and timestamp — the **evidentiary-weight signals** already visible for that value: whether the quote sits in a "(shipped)"-marked section, whether it is current-revision or lifted from an earlier revision (a phantom-grounding signal), its attribution (author/date) or lack of it, and relative modification order between the sources. The signals are noted at registration time, before adjudication begins, so the eventual adjudicator inherits the evidentiary posture rather than reconstructing it.

**Grounding.**
- `suggested/workflows/reconcile-grok-model-pick-persistence-drift.md`, step 1: "Note the evidentiary weights up front: Value A's quote is lifted from an earlier revision of a doc whose current text no longer contains it (a phantom-grounding signal), and neither current statement sits in a '(shipped)'-marked section covering Grok's pick specifically."
- `suggested/agent-updates/shipped-marker-doc-sections.md`: "the /model-scope reconciliation was settled largely on the strength of the '(shipped)' annotation plus timestamps" — the signals, not the quotes alone, carried the adjudication.
- `suggested/workflows/reconcile-model-scope-drift.md` registers Value B as quoted from "'TUI usage (shipped)' (modified *after* the convention doc)" — marker and modification order recorded as part of the value's identity.
- Existing law supplies the signal vocabulary but not the registration duty: marked claims outrank unmarked and older statements; an unattributed value cannot serve as evidence later.

**Why:** a TBD row freezes the fact, sometimes for a long interval, and the person who registers a drift is rarely the one who adjudicates it. The signals are cheapest to capture at discovery — the registrant has both sources open and can see which section is marked, which quote is current, and which doc moved last. Left uncaptured, they must be re-derived later against sources that may have been edited again in the meantime, and an adjudicator who skips the re-derivation weighs two quotes as equals when the workspace's own evidence hierarchy says they are not.

**How to apply:** when running the register-doc-drift skill, add a "weights" line under each competing value covering at minimum: shipped-marker status of the enclosing section, revision currency of the quote, attribution, and source modification timestamps. During adjudication, treat the recorded signals as the starting posture but re-verify them against present reality before relying on them — the row's snapshot is evidence about registration time, not a substitute for the current tree.
